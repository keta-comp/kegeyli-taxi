# JAYHUN TAXI

Kegeyli tumani taksi dispetcherlik xizmati uchun React + TypeScript + PWA loyiha.

**Maqsad:** Telegram Voice Chat ish jarayonini JAYHUN TAXI ilovasiga o'tkazish.

## Ishga tushirish

```bash
npm install
npm run dev
```

## Rollar
- Driver: online/offline, ovozli chat, buyurtmalar
- Operator: buyurtma, haydovchi tanlash, ovozli e'lon
- Admin: xodimlar, tariflar, statistika

## Status
Boshlang'ich PWA interfeys. Haqiqiy Supabase authentication va LiveKit ovozli aloqa production uchun alohida sozlanishi va real Android qurilmalarida sinovdan o'tishi kerak. Sof PWA Android ekran qulflanganda ovozli aloqani kafolatlamaydi.

## Dizayn
Oq fon, qora matn, sariq/gold aksent. Xarita va mijoz uchun ilova MVPga kirmaydi.
